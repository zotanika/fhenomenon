# Astra 감사 후 수정 결과 — 2026-10-28

프로젝트의 기존 구조를 유지하면서, 실제 계산의 정확성·메모리 수명·검증 결과의 신뢰성을 우선 수정했다. 이 수정은 네이티브 CKKS 전체 구현이나 GPU 성능 검증 완료를 뜻하지 않는다.

## 적용한 수정

| 영역 | 수정과 확인한 동작 |
|---|---|
| Session 계산 | 복합식의 Profile 전파, 보관된 중간 결과의 복사·수명 관리, 대입 후 입력 선택을 수정했다. 여러 실행에 걸쳐 암호문을 공유하는 변수는 계획 전에 같은 입력으로 정리하고, 이후 덮어쓰기는 독립된 결과로 유지한다. |
| Session 실행 경계 | 현재 Session 선택, 중첩 기록 거부, 기록 중 복호화 거부를 명확히 했다. 기록은 `Fhenon<int>`로 제한하고, float/double의 즉시 실행에 필요한 누락된 정의를 보완했다. 암호화되지 않은 값을 대입할 때 이전 암호문이 남는 문제도 차단했다. |
| 임시값과 진단 출력 | 내부 임시값을 실제 보관할 결과와 구분해 마지막 사용 후 해제한다. 자동 AST 출력은 제거하고, 명시적 출력은 공유 노드를 중복 전개하지 않게 했다. 디버그 로그는 선택적으로 켠다. |
| 실행기 계약 | HMULT 대체 실행에 필요한 모든 기본 연산을 요구한다. 위험한 실제 버퍼 겹침은 연산 전에 거부한다. 계획을 프로그램 전체 내용에 결합해 같은 길이의 변경된 프로그램도 잘못 실행하지 않는다. |
| 메모리 계획 | 입력의 초기 상주 상태를 정리한 뒤 예산을 적용한다. 직접 호출자가 중복된 실제 입력 핸들을 제공하는 경우와 바이트 합계의 정수 넘침을 차단한다. 알 수 없는 레벨 효과 값도 정의되지 않은 동작 없이 거부한다. |
| ToyFHE | 벡터에 대한 스칼라 연산·뺄셈·부호 반전을 슬롯별로 수행한다. 선택적인 packed f64 입출력을 추가하고, 길이·종류·비정상 값 검증을 추가했다. |
| CKKS 기반 계층 | 소수 곱의 대소 관계를 정확한 정수 연산으로 비교하고 합성수를 거부한다. Layout의 범위·형식·오버플로 검증을 강화하고 Arena 이동·초기화·Scope 수명 문제를 수정했다. 기존 ParamsId 값은 유지했다. |
| 빌드와 설치 | 테스트를 끈 빌드, 공개 헤더 설치, 전이 의존성 내보내기를 수정했다. 설치한 패키지만 사용하는 별도 프로그램으로 확인한다. |
| 실험 도구 | packed 계산을 실제로 실행하고 결과를 비교한다. 계획·실행·건너뜀·실패를 따로 표시하며, 필수 실행을 건너뛰면 실패한다. GPU 테스트가 0개인 경우도 실패한다. GPU 측정 코드는 완료 동기화를 포함하도록 바꿨다. |

## 검증 결과

기본 ToyFHE 구성에서 확인한 결과다.

- 새 Debug 빌드: CTest **23/23 통과**, GoogleTest **241개 통과**.
- 새 ASan/UBSan 빌드: LTO를 끄고 오류 즉시 중단 설정으로 CTest **23/23 통과**. LeakSanitizer 검증은 포함하지 않는다.
- Release, `BUILD_TEST=OFF`, `DISABLE_LTO=ON`: 빌드와 별도 설치 폴더의 외부 소비자 프로그램 실행 통과.
- packed 8×8 행렬–벡터 계산: 모든 출력 슬롯을 평문 기준값과 비교하고, 전용 연산과 기본 연산 대체 경로의 일치를 확인했다. 결과는 `planned=1 executed=1 skipped=0 failed=0`이다.
- 기존 64슬롯 matvec, 스칼라 정수·실수 전용 백엔드 호환성, 잘못된 옵션과 실행 생략의 실패 처리를 확인했다.
- 수치 범위를 넘는 ToyFHE `stats`·`logreg`는 실제 불일치를 실패로 보고한다. 이 실패를 정상적으로 감지하는 검사도 포함했다.
- 독립 Astra 검토에서 발견한 입력 공유·바이트 합계 넘침·Session 통합·옵션 검증과 대체 회전 연산 지원 판정 문제를 재현 후 수정했다. CKKS는 별도 정수 기준값과 경계 Layout·Arena 검사로 교차 확인했다.

## 남은 한계

Cheddar의 새 packed 입출력과 GPU 측정 경로는 이 CPU 장비에서 컴파일하거나 실행하지 못했다. GPU 성능 수치는 제시하지 않는다. 네이티브 CKKS의 평가·키 관련 미완성 계층도 이번 범위에 포함하지 않았다.

크기가 다른 버퍼의 Belady 정책은 휴리스틱이다. 메모리 모델에는 진입 시 상주량, 내부 작업 공간, 예약 메모리와 임시 3성분 암호문이 포함되지 않는다. ToyFHE의 바이트 모델은 packed 벡터의 실제 저장량을 나타내지 않는다.

ToyFHE는 보안용 구현이 아니며 수치 범위가 제한적이다. 실행 실패 시 앞서 성공한 연산을 되돌리는 트랜잭션 보장도 없다. 따라서 현재 상태를 모든 백엔드·입력에 대한 완성형 구현으로 판단하지 않는다.

재현 명령과 GPU 장비에서 수행할 다음 검증은 [packed 검증 안내](../benchmarks/corpus/README.md)에 정리했다.
