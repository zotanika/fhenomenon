# Native CKKS shared interface contract
All code namespace fhenomenon::ckks, C++17. Preserve original workspace audit changes. Root owns shared/root CMake and FHN/corpus. No commits. Implementers may own their layer CMake files; notify root new tests/sources. Root will register tests in test/CKKS/CMakeLists.txt. Core interfaces may only change after notifying root + other implementers.

## Storage.h (L2, storage agent)
PolySlab(size_t word_capacity): 64-byte aligned fixed owner, move-only, data() const/mutable, capacityWords(), no grow. Explicit clone optional, no implicit copy.
BasicRnsPoly<Word> public fields (this order): Word* data; size_t capacity_words; PolyLayout layout. Default/aggregate initialization. wellFormed() noexcept, limb(uint32_t) returns Word* (null for invalid index/view). Aliases RnsPolyView=BasicRnsPoly<uint64_t>, ConstRnsPolyView=BasicRnsPoly<const uint64_t>. free asConst(RnsPolyView) returns corresponding const view.
BasicCiphertext<Word> public fields (this order): Word* data; size_t capacity_words; size_t poly_stride_words; CiphertextLayout layout. wellFormed() noexcept validates alignment/capacity/nonoverlap/layout; poly(uint32_t) returns BasicRnsPoly<Word>. CiphertextView and ConstCiphertextView aliases. free asConst(CiphertextView). Views copy cheaply, never own. Output functions receive CiphertextView& and update layout only after successful validation/computation. Caller supplies fixed-capacity slab (3 polynomials * fullQP limb stride for backend; layers may use smaller sufficient storage).
SwitchKeyKind enum {Relinearization,Galois}.
EvaluationKeyView public fields: const ConstCiphertextView* digits=nullptr; uint32_t digit_count=0; ParamsId params_id{}; uint32_t log_degree=0, main_count=0, aux_count=0; SwitchKeyKind kind=Relinearization; uint64_t galois_element=1. Each digit is 2-polynomial fullQP NTT view, layout.scale=1. Main/aux offsets follow original fullQ count. No key ownership/generation/secret in this header.

## CrtTables.h (L1, storage agent)

Allocation only create. Garner inverses precomputed. Digits validate input residues in toMixedRadix; downstream digits assumed valid. Exact halfQ sign lexicographic from high digit. Negative float reconstruction from complement+1 avoids cancellation. No __int128 spelling outside ModArith.h.

## Backend/root integration
New optional host-only FhnClientCtx* handle and create/destroy/prepare/encrypt/decrypt vector exports. FhnBackendCtx contains only public evaluation material, no secret/client backpointer/global registry. Client owns SK/PK/EK; context weak EK observers borrow percall. Corpus loader resolves client group and preserves olddata-plane compatibility. prepare(client,program) derives needed relinearization/Galois keys before execution. No common samectx decrypt export in native plugin. Native prefix ckks_. Default conservative profile N8192,Q50+40+40,P60,dnum3,scale40. Freshlevel2. Backend rejects unsupported sparse secrets, terminalprimes, emptyfulldigits and configured QPbits above public conservative ternary table. No bootstrapping, GPU, perf claims, or security certification.
